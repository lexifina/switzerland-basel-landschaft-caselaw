# BL Gerichte 2019-08-27-sr-4

## Regeste

Erkennungsdienstliche Erfassung, WSA-Abnahme und Auftrag zur Erstellung eines DNA-Profils / SachbeschädigungBei verschiedenen Sachbeschädigungen über einen längeren Zeitraum können die einzelnen Schadenssummen nicht einfach zusammengerechnet werden, so dass eine qualifizierte Sachbeschädigung gemäss Art. 144 Abs. 3 StGB entsteht, sondern nur, wenn aufgrund der räumlichen und zeitlichen Nähe eine Handlungseinheit vorliegt (E. 2.4.5).
